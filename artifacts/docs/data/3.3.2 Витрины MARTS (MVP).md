# 3.3.2 Витрины MARTS (MVP)

Документ фиксирует реализацию подпункта `3.2` из верхнеуровневого чек-листа с опорой на согласованные ручные решения из [3.3.1 Ручные исследования перед реализацией MARTS](3.3.1%20Ручные%20исследования%20перед%20реализацией%20MARTS.md).

## 1) Что реализовано

Добавлена миграция витрин:

- [`sql/db/project/migrations/008_marts_vitrines_mvp.sql`](../../../sql/db/project/migrations/008_marts_vitrines_mvp.sql)

Реализованы 3 витрины:

- `mart.market_daily_kpis`
- `mart.employer_activity`
- `mart.vacancy_daily_snapshot` (опорная/техническая, как опциональная из чек-листа)

## 2) Бизнес-правила, зафиксированные в реализации

- Таймзона дня `dt`: `Europe/Moscow`.
- `active`: `is_active = true` на конец дня в snapshot.
- `new`: первое появление вакансии (`first_seen_dt = dt`).
- `closed`: переход `active -> inactive` между соседними днями по `vacancy_id`.
- `UNKNOWN`-категории включены в агрегаты как полноценные категории.
- `UNKNOWN_EMPLOYER:*` включается в employer-витрину, отмечается флагом `unknown_employer_flag`.

## 3) Таблицы MART

### 3.1 `mart.vacancy_daily_snapshot`

Назначение: ежедневное состояние вакансии (`1 строка = vacancy_id на день dt`).

Ключ:

- `primary key (dt, vacancy_id)`

Ключевые поля:

- `employer_key`, `region_norm`, `profession_norm`
- `is_active`, `salary_mid`, `currency`
- `source_modified_at`, `first_seen_dt`

### 3.2 `mart.market_daily_kpis`

Назначение: KPI рынка по `dt/region_norm/profession_norm`.

Ключ:

- `primary key (dt, region_norm, profession_norm)`

Ключевые поля:

- `vacancies_total`, `active_vacancies`, `new_vacancies`, `closed_vacancies`
- `salary_coverage_pct`
- `salary_median`, `salary_p75`, `salary_p90`
- `timezone_name` (`Europe/Moscow`)

### 3.3 `mart.employer_activity`

Назначение: активность работодателей по дням.

Ключ:

- `primary key (dt, employer_key, region_norm)`

Ключевые поля:

- `unknown_employer_flag`
- `vacancies_total`, `active_vacancies`, `new_vacancies`, `closed_vacancies`
- `timezone_name` (`Europe/Moscow`)

## 4) Функции refresh

Реализованы функции:

- `mart.refresh_vacancy_daily_snapshot(p_date_from, p_date_to)`
- `mart.refresh_market_daily_kpis(p_date_from, p_date_to)`
- `mart.refresh_employer_activity(p_date_from, p_date_to)`
- `mart.refresh_all_vitrines(p_date_from, p_date_to)`

Порядок full-refresh:

1. строится snapshot,
2. затем market KPI,
3. затем employer activity.

Пример запуска:

```sql
select * from mart.refresh_all_vitrines();
```

## 5) Результат для чек-листа 3.2

- `mart_market_daily_kpis` реализована.
- `mart_employer_activity` реализована.
- Опциональная `mart_vacancy_daily_snapshot` реализована.
