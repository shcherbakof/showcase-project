## 1) Назначение

Excel-витрина отвечает на вопрос: что происходит с рынком вакансий сейчас и где есть заметные отклонения, в виде файла для бизнес-потребителя.

## 2) Где лежит файл

- Каталог: `artifacts/reports/excel/`
- Формат имени: `business_health_YYYY-MM-DD_HH-MM-SS.xlsx`

## 3) Как читать листы

1. `Легенда`:

- цель отчёта,
- расшифровка листов,
- статус отчёта,
- дата данных,
- контакты (`team/email/note`).

2. `Сводка`:

- ключевые KPI за актуальную дату данных (`active/new/closed/net/salary`).

3. `Топ регионы` / `Топ профессии` / `Топ работодатели`:

- рейтинг Top-10 по активным вакансиям.

4. `Исключения`:

- сигналы `warning/error` по динамике,
- причина `no_data` при отсутствии данных.

## 4) Статусы отчёта

- `ok`: отчет сформирован по данным.
- `no_data`: файл создан, но данные в источниках отсутствуют.

## 5) Что делать при вопросах

Контакты берутся из конфигурации отчёта:
