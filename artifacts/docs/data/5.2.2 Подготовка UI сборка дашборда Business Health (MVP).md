# 5.2.2 Подготовка UI сборка дашборда Business Health (MVP)

Документ фиксирует реализацию UI-сборки дашборда Superset для блока `5.2` из [`artifacts/docs/data/3. Шаги выполнения checklist.md`](3.%20Шаги%20выполнения%20checklist.md).

## 1) Что реализовано

1. Добавлен idempotent-скрипт сборки charts + dashboard:

- [`superset/assets/build_business_health_dashboard.py`](../../../superset/assets/build_business_health_dashboard.py)

2. Подключен автозапуск сборки в Superset bootstrap:

- [`superset/bootstrap.sh`](../../../superset/bootstrap.sh)

3. Сборка выполняется после импорта datasets (`datasources.yaml`) и формирует:

- Dashboard: `Business Health (MVP)` (`slug=business-health-mvp`)
- 6 charts:
  - `[MVP-BH] KPI Карточки`
  - `[MVP-BH] Динамика рынка`
  - `[MVP-BH] Зарплатные тренды`
  - `[MVP-BH] Топ регионов`
  - `[MVP-BH] Топ профессий`
  - `[MVP-BH] Топ работодателей`
  - native time filter: `КРАСНАЯ КНОПКА: Период (14/30/90)` (default: `Last 30 days`)

## 2) Технический подход

- Подход: программный upsert через Superset ORM в `app_context`.
- Идемпотентность:
  - повторный запуск не создает дубликаты dashboard/charts;
  - существующие объекты обновляются по `dashboard_title` и `slice_name`.
- Перед созданием/обновлением chart выполняется `dataset.fetch_metadata()`:
  - это синхронизирует колонки datasets из БД,
  - предотвращает ошибки вида `Columns missing in dataset`.
- Layout:
  - формируется `position_json` в grid-структуре (2 charts в строке).
- В `json_metadata` дашборда добавлен native filter (`filter_time`) по колонке `dt` для всех datasets Business Health.
