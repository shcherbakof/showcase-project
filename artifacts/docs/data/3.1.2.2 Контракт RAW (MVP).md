# 3.1.2.2 Минимальный “контракт” RAW (MVP)

Основано на примере [`data/3.1.1.2_example.json`](3.1.1.2_example.json) (внутри `results.vacancies[].vacancy`).

## Единица RAW-записи

**1 строка в `raw.vacancies` = 1 версия 1 вакансии** (append-only), где `payload` — исходный JSON объекта `vacancy` целиком.

## Обязательные поля (колонки) RAW-записи

Эти поля **должны быть заполнены для каждой строки** в `raw.vacancies`:

- `run_id` — идентификатор прогона (uuid/text)
- `ingested_at` — время загрузки (timestamptz, UTC)
- `source_system` — константа источника (например, `trudvsem`)
- `endpoint` — вызванный эндпоинт (например, `/api/v1/vacancies` или `/api/v1/vacancies/region/{code}`)
- `request_params` — параметры запроса (jsonb: region, modifiedFrom/To, offset, limit, любые флаги)
- `http_status` — HTTP статус ответа (int)
- `payload` — исходный объект вакансии (jsonb)
- `vacancy_id` — извлечённый ключ вакансии (text), из payload: `payload->>'id'`
- `source_modified_at_raw` — “версионность” как строка (text), из payload: `payload->>'date_modify'`
- `region_code_raw` — код региона как строка (text), из payload: `payload->'region'->>'region_code'`

## Обязательные поля внутри payload (для приёма в RAW)

Если любого из пунктов нет — запись **не попадает в `raw.vacancies`**, а уходит в `raw.quarantine`:

- `id` (пример: `4cfe31f0-0e3c-11f1-a990-837b73ca4e2b`)
- `date_modify` (пример: `2026-02-20T13:34:06+0300`)
- `region.region_code` (пример: `6600000000000`)

## Рекомендуемые (не обязательные, но полезные)

- `response_meta` (jsonb) — `meta` из ответа (например, `total`, `limit`, `offset` если есть)
- `payload_sha256` (text/bytea) — хеш payload для дебага/контроля дублей (не обязателен, если уникальность = `vacancy_id + source_modified_at_raw`)
- `source_modified_at` (timestamptz) — распарсенное значение `source_modified_at_raw` (удобно для SQL и watermark)
- `request_url` (text) — полный URL для воспроизведения (если хочется быстрее дебажить)

## Минимальный уникальный ключ “версии” (идемпотентность)

Для `ON CONFLICT DO NOTHING` достаточно:

- (`source_system`, `vacancy_id`, `source_modified_at_raw`)

Если на практике окажется, что `date_modify` иногда повторяется для разных версий — добавь в ключ `payload_sha256`.
