# 3.2.3 STG загрузка vacancies из RAW (MVP)

Документ фиксирует реализацию подпункта `2.3` из верхнеуровневого чек-листа.

## 1) Что реализовано

Реализована функция загрузки STG-слоя:

- `stg.load_vacancies_from_raw(p_run_id text default null)`
- файл миграции: [`sql/db/project/migrations/006_stg_load_from_raw_mvp.sql`](../../../sql/db/project/migrations/006_stg_load_from_raw_mvp.sql)

Функция переносит данные из `raw.vacancies` в `stg.vacancies` с детерминированным upsert.

## 2) Выбор актуальной версии из RAW

Правило выбора 1 актуальной строки на `vacancy_id`:

1. максимальный `source_modified_at`;
2. при равенстве — максимальный `ingested_at`;
3. при равенстве — максимальный `raw.id`.

Если `source_modified_at` отсутствует, используется fallback `ingested_at`.

## 3) Upsert в STG (идемпотентно, детерминированно)

`ON CONFLICT (vacancy_id) DO UPDATE` выполняется только если входящая версия «новее» текущей по детерминированному правилу:

1. `excluded.source_modified_at > stg.source_modified_at`;
2. или при равном `source_modified_at`: `excluded.last_raw_ingested_at > stg.last_raw_ingested_at`;
3. или при полном равенстве времени: лексикографически больший `run_id`.

Это исключает недетерминированные перезаписи и делает повторный запуск идемпотентным.

## 4) Нормализация в процессе загрузки

Во время upsert применяются утверждённые правила блока `2.2`:

- `status_raw -> status_norm/is_active` через `stg.ref_vacancy_status_map`;
- `salary_raw -> salary_from/salary_to/salary_mid/currency`;
- `region_raw/profession_raw -> region_norm/profession_norm`.

## 5) Параметр запуска и результат

- `p_run_id is null`: пересчитать STG по всем данным RAW (по правилу latest per vacancy).
- `p_run_id = '<run_id>'`: взять только RAW-строки указанного run.

Функция возвращает счётчики:

- `processed_count`
- `inserted_count`
- `updated_count`

Пример запуска:

```sql
select * from stg.load_vacancies_from_raw();
select * from stg.load_vacancies_from_raw('manual_20260222_66_v6');
```

## 6) Результат для чек-листа 2.3

- Реализован upsert в `stg.*` с идемпотентным поведением.
- Зафиксирован и реализован детерминированный выбор актуальной версии из RAW (`source_modified_at`, fallback `ingested_at`).
