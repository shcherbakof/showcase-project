# 3.1.5.3 Ручной backfill CLI (MVP)

Документ фиксирует реализацию подпункта `1.5.3`: ручной backfill-инструмент (не DAG) с тем же контрактом записи в `raw.*` и `mon.pipeline_runs`.

## Реализация

- CLI: [`src/jobs/raw_backfill_cli.py`](../../../src/jobs/raw_backfill_cli.py)
- Wrapper: [`scripts/raw-backfill.sh`](../../../scripts/raw-backfill.sh)
- Make target: `make backfill`

## Что поддерживает CLI

1. Параметры периода/регионов/лимитов:
- `--window-from` (обязательно)
- `--window-to` (обязательно)
- `--region-code` (опционально)
- `--limit`, `--max-pages`, `--max-items`

2. Тип запуска:
- `run_type=backfill` фиксируется в `PipelineRunContext`.

3. Контракт записи:
- пишет в `raw.vacancies` и `raw.quarantine` через `RawBatchWriter`;
- пишет итог в `mon.pipeline_runs` через `PipelineRunsWriter`.

4. Итоговый отчет в stdout:
- `run_id`, `status`,
- `requests_total/requests_success`,
- `items_extracted`,
- `raw_rows_inserted/raw_rows_skipped_conflict`,
- `quarantine_rows`,
- `error_summary`.

## Примеры запуска

Через make:

```bash
make backfill ARGS="--window-from 2026-02-21T00:00:00+00:00 --window-to 2026-02-21T23:59:59+00:00 --region-code 77 --limit 100 --max-pages 200"
```

Напрямую:

```bash
.venv/bin/python src/jobs/raw_backfill_cli.py \
  --window-from 2026-02-21T00:00:00+00:00 \
  --window-to 2026-02-21T23:59:59+00:00 \
  --region-code 77
```

Dry-run (без записи в БД):

```bash
make backfill ARGS="--window-from 2026-02-21T00:00:00+00:00 --window-to 2026-02-21T23:59:59+00:00 --dry-run --max-pages 0"
```
