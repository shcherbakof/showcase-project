# 6.2 Генерация Excel витрины Business Health (MVP)

Документ фиксирует реализацию генерации ежедневной Excel-витрины для блока `6` из [`artifacts/docs/data/3. Шаги выполнения checklist.md`](3.%20Шаги%20выполнения%20checklist.md).

## 1) Что реализовано

1. Добавлен генератор Excel-отчёта:

- [`src/jobs/business_health_excel_report.py`](../../../src/jobs/business_health_excel_report.py)

2. Добавлен конфиг отчёта (контакты и русские названия листов):

- [`src/jobs/config/business_health_report.json`](../../../src/jobs/config/business_health_report.json)

3. Генерация встроена в end-to-end DAG:

- [`airflow/dags/stg_marts_pipeline_dag.py`](../../../airflow/dags/stg_marts_pipeline_dag.py)
- новая задача: `generate_excel_report`

4. Обновлены зависимости Airflow для экспорта XLSX:

- [`requirements-airflow.txt`](../../../requirements-airflow.txt) (`openpyxl`)

## 2) Логика формирования отчёта

- Файл формируется по системной дате/времени генерации.
- Путь вывода по умолчанию: `artifacts/reports/excel/`.
- Шаблон имени: `business_health_YYYY-MM-DD_HH-MM-SS.xlsx`.
- Всегда создаётся файл, даже при отсутствии данных (`status=no_data`).

## 3) Состав листов (на русском)

1. `Легенда` (титульный лист)
2. `Сводка`
3. `Топ регионы`
4. `Топ профессии`
5. `Топ работодатели`
6. `Исключения`

## 4) Источники данных (утверждённый вариант B)

- `Сводка` и `Исключения`: `mon.v_business_health_*`.
- Топ-листы и детализация: `mart.*`.

## 5) Оркестрация и статус run

- Порядок в DAG: `prepare -> refresh_marts -> run_quality_checks -> generate_excel_report -> emit_report_quality_marker -> write_run_stats`.
- Если `generate_excel_report` падает, run получает `partial` (если нет критических ошибок в STG/MART/DQ).
- Путь к Excel-файлу фиксируется в `error_summary` и quality-marker.

## 6) Параметры конфигурации

- Контакты вынесены в JSON-конфиг (`team/email/note`), без использования `env`.
- Опциональные env для пути:
  - `EXCEL_REPORT_OUTPUT_DIR`
  - `EXCEL_REPORT_CONFIG_PATH`
