# Market Monitoring Pipeline (Работа России API)

## Описание

Проект реализует автоматизированный пайплайн сбора и анализа данных о вакансиях и работодателях на основе официального API «Работа России».

Цель — обеспечить регулярную управленческую отчётность и мониторинг состояния данных.

## Архитектура

**Источник:** API «Работа России»
**Оркестрация:** Airflow
**Обработка:** Python
**Хранилище:** PostgreSQL
**Мониторинг:** Superset
**Бизнес-отчётность:** Excel (ежедневно)

## Логика работы

1. Инкрементальная загрузка вакансий по watermark (modifiedFrom/modifiedTo)
2. Append-only raw слой
3. Дедупликация и нормализация в staging
4. Формирование аналитических витрин:
   - активные / новые / закрытые вакансии
   - медианная зарплата
   - динамика по регионам
   - активность работодателей

5. Контроль качества данных:
   - freshness
   - объёмы загрузки
   - доля некорректных записей

6. Генерация ежедневного Excel-отчёта

## Особенности реализации

- Идемпотентность загрузки
- Watermark-инкремент
- Retry и обработка ошибок API
- Разделение управленческой витрины и технического мониторинга
- Контроль качества данных на нескольких уровнях

## Бизнес-ценность

- Автоматизация отчётности
- Актуальные данные без ручной обработки
- Прозрачность состояния пайплайна
- Возможность оперативного анализа рынка труда
