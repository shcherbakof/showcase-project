# 3.1.8.1 Smoke RAW — пустое окно

Документ фиксирует проверку подпункта `1.6.3`: пустое окно завершается со статусом `success`, метрики равны `0`, запись run существует.

## Сценарий проверки

Выполнен контролируемый локальный smoke-прогон для пустого окна:

- `RUN_ID = smoke-empty-3e24cc1b-17d2-4c98-923a-b8e72428bc75`
- окно:
  - `window_from = 2035-01-01T00:00:00+00:00`
  - `window_to = 2035-01-01T01:00:00+00:00`

В `mon.pipeline_runs` записан итоговый run через `RunMetricsAccumulator`/`PipelineRunsWriter` без добавления fetch/write данных.

## Результаты

- `RAW_COUNT = 0` (в `raw.vacancies` по `run_id`)
- `MON_COUNT = 1` (в `mon.pipeline_runs` по `run_id`)
- `STATUS = success`
- `REQUESTS_TOTAL = 0`
- `REQUESTS_SUCCESS = 0`
- `ITEMS_EXTRACTED = 0`
- `RAW_INSERTED = 0`
- `RAW_SKIPPED = 0`
- `QUARANTINE_ROWS = 0`

## Вывод

Критерий `1.6.3` подтвержден: пустое окно дает `success`, нулевые метрики и запись run.
