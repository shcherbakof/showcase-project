## Что означает пункт 3.1 и зачем он нужен

Цель: поднять **один предсказуемый Postgres-сервис** как первый модуль стека, чтобы дальше на него правильно “навешивались” `db-init`, Airflow, Superset через `depends_on: service_healthy`, а данные переживали перезапуски благодаря named volume.

Разбор подпунктов:

- **image Postgres (tag через env, “предпоследний стабильный” зафиксировать)**
  Ты фиксируешь версию образа в `.env` → воспроизводимость у ревьюера и у тебя. “Предпоследний стабильный” в практике этого проекта = **предыдущий major** (например, 16 при актуальном 17), но всё равно **pin через env**.

- **порт наружу по умолчанию (`POSTGRES_HOST_PORT`)**
  Удобно для отладки из хоста (DBeaver/psql/IDE). Порт должен переопределяться через env.

- **примонтировать `works_on_russia_pgdata` в `PGDATA`**
  Данные должны жить в named volume (кросс-ОС стабильно). Монтируем volume прямо в `PGDATA`, чтобы не было сюрпризов с путями.

- **healthcheck (`pg_isready`)**
  Это “контракт готовности”: Postgres может быть “running”, но ещё не принимать коннекты. Healthcheck нужен, чтобы `db-init` стартовал строго после готовности.

- **логирование (дефолтное, но читаемое)**
  Минимум: docker `json-file` ротация (чтобы логи не раздули диск). Плюс (опционально) `log_line_prefix`, чтобы в логах сразу было видно время/пользователя/БД/пид.

## Конкретно по шагам (что сделать)

1. В `.env.example` добавить переменные Postgres:

- `POSTGRES_IMAGE_TAG`
- `POSTGRES_HOST_PORT`
- `POSTGRES_SUPERUSER`, `POSTGRES_SUPERPASS`
- `POSTGRES_PGDATA`
- `POSTGRES_LOCALE`, `POSTGRES_ENCODING`
- (у тебя уже должны быть) `COMPOSE_PROJECT_NAME`, `TZ`, `LANG`, `LC_ALL`

2. В `compose.yaml`:

- в `services` добавить `postgres` с `profiles: ["db"]`
- `image: postgres:${POSTGRES_IMAGE_TAG}`
- `ports: "${POSTGRES_HOST_PORT}:5432"`
- `volumes: pgdata:${POSTGRES_PGDATA}`
- `environment: PGDATA=${POSTGRES_PGDATA}` + креды
- `healthcheck` на `pg_isready`
- `logging` с ротацией
- подключить к единой сети `${COMPOSE_PROJECT_NAME}_net`

3. Проверка:

- `docker compose --env-file .env.example config`
- `docker compose --profile db up -d postgres`
- `docker compose ps` (должен быть `healthy`)

## Готовое решение

### `.env.example` (добавь/обнови)

```dotenv
# Project naming
COMPOSE_PROJECT_NAME=works_on_russia

# Timezone/locale (единые)
TZ=Europe/Moscow
LANG=C.UTF-8
LC_ALL=C.UTF-8

# Postgres (pin version)
# "предпоследний стабильный" держим как previous major, но руками фиксируешь тут
POSTGRES_IMAGE_TAG=16
POSTGRES_HOST_PORT=5432

# Superuser (локально, пример)
POSTGRES_SUPERUSER=postgres
POSTGRES_SUPERPASS=postgres

# PGDATA (монтируем volume прямо сюда)
POSTGRES_PGDATA=/var/lib/postgresql/data/pgdata

# initdb defaults
POSTGRES_LOCALE=C.UTF-8
POSTGRES_ENCODING=UTF8
```

### `compose.yaml` (минимально корректный модуль Postgres)

```yaml
name: ${COMPOSE_PROJECT_NAME}

x-common-env: &common_env
  TZ: ${TZ}
  LANG: ${LANG}
  LC_ALL: ${LC_ALL}

services:
  postgres:
    image: postgres:${POSTGRES_IMAGE_TAG}
    profiles: ["db"]
    container_name: ${COMPOSE_PROJECT_NAME}_postgres
    restart: unless-stopped

    environment:
      <<: *common_env
      POSTGRES_USER: ${POSTGRES_SUPERUSER}
      POSTGRES_PASSWORD: ${POSTGRES_SUPERPASS}
      POSTGRES_DB: postgres
      PGDATA: ${POSTGRES_PGDATA}
      POSTGRES_INITDB_ARGS: "--encoding=${POSTGRES_ENCODING} --locale=${POSTGRES_LOCALE}"

    ports:
      - "${POSTGRES_HOST_PORT}:5432"

    volumes:
      - pgdata:${POSTGRES_PGDATA}

    networks:
      - app_net

    healthcheck:
      test:
        [
          "CMD-SHELL",
          "pg_isready -U $$POSTGRES_USER -d postgres -h 127.0.0.1 -p 5432",
        ]
      interval: 5s
      timeout: 3s
      retries: 20
      start_period: 10s

    logging:
      driver: json-file
      options:
        max-size: "10m"
        max-file: "3"

    command:
      - postgres
      - -c
      - log_timezone=${TZ}
      - -c
      - log_line_prefix=%m [%p] %q%u@%d

networks:
  app_net:
    name: ${COMPOSE_PROJECT_NAME}_net
    driver: bridge

volumes:
  pgdata:
    name: ${COMPOSE_PROJECT_NAME}_pgdata
```
